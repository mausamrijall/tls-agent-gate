Site A — Passive Capability Provider

Holds no autonomous agent loop. Publishes its identity/manifest and exposes protected capability endpoints behind the tls-agent-gate verifier — unsigned/untrusted callers are rejected with 401/403.

Protected API

Try it without an agent signature: curl -i http://localhost:4173/api/agent/search?q=agents

Expected: 401 {"error":{"code":"ERR_MISSING_IDENTITY_HEADER",…}}

Then trigger a signed call from Site B (http://localhost:4174) — the response will include X-Verified-Agent: localhost.

Files

  • /.well-known/agent-identity.json — TLS-anchored identity (Ed25519)
  • /agent-manifest.json — Open Agentic Web manifest
